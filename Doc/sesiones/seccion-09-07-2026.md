### Portal proveedores — fix detección mobile (10/07/2026)

**Archivo modificado:** `app/proveedores/page.tsx`

**Bug:** `isMobile` usaba `useState(false)` + `useEffect(() => window.innerWidth < 768)` propio. En producción este efecto no actualizaba el estado correctamente en el dispositivo físico, dejando `isMobile = false` permanentemente → el sidebar nunca se ocultaba.

**Fix:** Eliminado el estado local y el `useEffect` de detección; reemplazado por `const { isMobile } = useSidebar()`. El `SidebarProvider` está en el root layout y ya envuelve también el portal de proveedores. Esta es la misma fuente que usa el panel admin, que funciona correctamente.
