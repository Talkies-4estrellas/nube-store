### Diseño responsivo — layout adaptativo

**Archivos nuevos/modificados:**
| Archivo | Cambio |
|---------|--------|
| `lib/sidebar-context.tsx` | Nuevo — contexto `{ open, toggle, close, isMobile }` |
| `app/layout.tsx` | Añade `<SidebarProvider>` wrapping `<AppChrome>` |
| `components/AppChrome.tsx` | `marginLeft`/`padding` condicionales por `isMobile`; overlay al abrir sidebar |
| `components/Sidebar.tsx` | En mobile: `transform: translateX(-100%/0)` + `transition`; z-index 200 |
| `components/Topbar.tsx` | En mobile: `left: 0`; botón hamburguesa ☰/× a la izquierda; logo y nombre de usuario ocultos |
| `app/globals.css` | Clases responsivas: `stat-grid`, `grid-3`, `table-wrap`, `panel-layout`, `panel-aside`, `filter-row` |

**Descripción:**
- `SidebarContext` detecta `window.innerWidth < 768` en un `useEffect` con listener de `resize`
- El sidebar se cierra automáticamente al cambiar de ruta (listener en `pathname`)
- En desktop el contexto no interfiere — `isMobile = false`, `open` no aplica
- Las clases CSS usan `!important` para sobreescribir los inline styles en media queries
- Overlay semitransparente + `backdropFilter: blur(1px)` al abrir sidebar en móvil; click cierra

**Breakpoints:**
| Clase | >900px | 480-900px | <480px |
|---|---|---|---|
| `stat-grid` | 4 cols | 2 cols | 1 col |
| `grid-3` | 3 cols | 2 cols | 1 col |
| `table-wrap` | normal | scroll-x | scroll-x |
| `panel-layout` | flex row | flex row | flex column |
| `filter-row` | flex row | flex row | flex column, 100% |
