**Incidente durante el trabajo, ya resuelto:** un intento de borrar un bloque de código
muerto con `Get-Content`/`Set-Content` de PowerShell corrompió la codificación UTF-8 de
todo `app/proveedores/page.tsx` (tildes y emojis se volvieron mojibake). Se detectó
antes de seguir, se confirmó que el commit anterior (`2638dde`) ya tenía a salvo todo
el trabajo de la sesión previa, se revirtió el archivo con `git checkout` y se rehizo
el rediseño de cero usando solo el editor de archivos.
**Why:** PowerShell 5.1 no usa UTF-8 por defecto en `Get-Content`/`Set-Content` sin
`-Encoding utf8` explícito en ambos lados, y aun así puede perder caracteres fuera de
Latin-1 (emojis) en el roundtrip.
**How to apply:** para borrar/mover bloques grandes de código con caracteres
especiales (tildes, emojis) en este proyecto, usar siempre el editor de archivos
(Edit/Write), nunca `Get-Content`/`Set-Content` de PowerShell ni `sed` sobre el archivo
completo.
