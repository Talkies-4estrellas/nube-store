# Sesión de trabajo — 13/08/2026

## Resumen del día

Sesión corta enfocada en un solo tema: qué tan fácil es de usar el panel
administrativo para alguien nuevo. El usuario pidió un análisis de dónde
se confunde más un usuario real dentro del panel; se hizo una auditoría
real leyendo el código (menú lateral, Configuración, Dashboard, flujo de
solicitudes) en vez de especular, y se armó una lista de 7 puntos de
confusión concretos con evidencia (por ejemplo: "Proveedores" no tiene su
propio botón en el menú, vive escondido dentro de "Clientes"; "Mensajes"
y "Comentarios" suenan igual pero son cosas distintas; los switches de
pago se pueden activar sin credenciales sin que la interfaz avise). A
partir de esa auditoría, el usuario pidió un panel de ayuda dentro del
Dashboard: un botón "?" que despliega preguntas frecuentes por categoría,
y al abrir cada una muestra explicación + confusión común + mini
tutorial. Se diseñó el contenido completo de las 12 preguntas antes de
programar, se confirmó con el usuario, y se implementó.

La sesión continuó bastante más de lo previsto: segunda ronda de
auditoría (4 preguntas nuevas, incluyendo dos huecos reales del panel —
crear empleados nuevos no se puede hacer desde ningún botón, y Punto de
Venta no tiene ningún enlace en el menú), se agregó "¿Por qué pasa?" y
"Posible solución" a las 16 preguntas, se corrigió que el panel tapaba
el contenido del Dashboard (ahora lo empuja a un costado, con
salvaguarda para ventanas angostas), se cambió para que no se cierre
solo al elegir una pregunta, y se cerró con un textbox de pregunta
libre con lógica híbrida: búsqueda local instantánea + un botón aparte
para preguntarle a Gemini si nada local resuelve la duda.
